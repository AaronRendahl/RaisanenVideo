Tape Archiving Specification

Unified Text Format & Metadata Schema for process_tape.sh

1. Column Layout

Every non-comment line consists of 6 pipe-delimited (|) columns:

IDX | START | END | TITLE / CHAPTER | DATE | CROPS
Col Name Description
1 IDX Numeric identifier. Integer (06) = Output video clip. Decimal (06.1) = Subchapter. Blank ( ) = Uncut Master Tape.
2 START Start timestamp (HH:MM:SS.mmm).
3 END End timestamp (HH:MM:SS.mmm). Optional if continuous.
4 TITLE / CHAPTER Output clip title (on integer/blank rows) or subchapter title.
5 DATE ISO date (YYYY-MM-DD or YYYY). Optional trailing field.
6 CROPS Crop boundary L|R|T|B (e.g., 12|24|0|8). Optional trailing field.

2. Formatting & Parsing Rules

  • Whitespace Tolerance: Leading/trailing whitespace around pipes is automatically stripped by the parser. Spaced or padded columns are fully valid.
  • Optional Trailing Pipes: Unspecified DATE and CROPS fields can leave off trailing pipes entirely.
  • Auto-Chaining: Continuous subchapters only require a START timestamp. The END time is inferred from the subsequent row's START. The last subchapter requires an explicit END time.
  • Blank IDX Master Tape Shortcut: Leaving IDX blank on line 1 sets UNCUT_MODE=true. Following rows numbered as whole integers (1, 2, 3) automatically parse as subchapters of the single master video.

4. Parser State Logic Reference

When parsing each line sequentially in process_tape.sh:

  1. Header Directive Check:
    Lines starting with ## configure script-wide defaults (e.g., ## Crop: 12|24|0|8). Comments starting with # or empty lines are ignored.
  2. Blank IDX Line Encountered (Uncut Master Tape):
    Sets UNCUT_MODE=true. Stores the primary master title, date, and crops. Sets parent clip START to 00:00:00.000 (or earliest subchapter timestamp).
  3. Integer IDX Line Encountered (e.g., 06):
    Finalizes and writes out any previously buffered video clip. Initializes a new parent clip structure storing title, date, and crop settings.
  4. Decimal IDX or Subchapter Integer Line Encountered (e.g., 06.02 or 2 under Uncut Mode):
    If the preceding subchapter has an empty END field, assigns prev.END = curr.START. Calculates relative offset (Subchapter START - Parent Clip START) and appends to the FFMETADATA buffer.
  5. End of File / Boundary Finalization:
    Sets Parent START = min(subchapters) and Parent END = max(subchapters). Triggers a two-stage FFmpeg process to re-encode video segments and write embedded Matroska XML/FFMETADATA chapter structures.
